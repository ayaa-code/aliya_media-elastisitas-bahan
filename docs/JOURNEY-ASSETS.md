# Journey visuals

assets/journey-background.webp is the final compressed 3D-look landscape, created with the built-in image tool using the approved concept as reference. Prompt: distant rolling green hills, village and waterfall/river, blue sky, soft dimensional cartoon sunlight; no characters, gameplay platforms, UI, birds or planes. It is only the slow parallax backdrop; native SVG layers provide moving clouds, occasional birds and plane, nearby trees, dimensional gradient/textured grass platforms, obstacles, checkpoints, stars and sprite character.

The environment is 2.5D rather than a real-time 3D scene. Background is converted with scripts/pack-environment.cjs; Bouncie uses the approved transparent sprite atlas documented separately. The optional chase feature from the earlier version has been removed, including its creature artwork, collision, penalty and mode setting.
