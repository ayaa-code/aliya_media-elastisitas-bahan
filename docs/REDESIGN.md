# Desain pastel dan akses belajar

Login/dashboard memakai gambar desain yang disetujui: mint–ivory–sky pada hero, peach–yellow pada materi, aqua–lavender pada game; teks navy dan tombol hijau–teal/biru gelap. Mode kontras tinggi mengganti gradasi kartu dengan permukaan putih berbingkai gelap.

## Aset yang dibuat dengan built-in image generation

- assets/bouncie-wave.webp: empat frame 2×2, masing-masing 384×512. Prompt memakai desain Bouncie yang disetujui sebagai referensi: wajah, kuncir cokelat/ikat kuning, kaus turquoise bersimbol pegas putih, celana kuning dan sepatu navy/putih; pose idle, telapak menyapa miring kiri, miring kanan, lalu tangan turun. Transparan, tanpa label/latar. Normalisasi pijakan dan pengemasan mekanis memakai scripts/pack-redesign.cjs. Pemutaran sekali sekitar 3,5 detik, bubble sinkron; Sapa Bouncie memutar ulang. Mode reduce motion memakai pose statis. Tidak memakai rotasi seluruh gambar untuk berpura-pura melambai.
- assets/book-icon.webp: prompt buku terbuka 3D bersampul teal, halaman ivory dan bookmark kuning, transparan tanpa huruf/latar.
- assets/game-icon.webp: prompt gamepad biru 3D, tombol kuning dan simbol pegas putih, transparan tanpa logo/latar.

Ilustrasi pertanyaan dan sumber halaman dijelaskan terpisah pada SUMBER-ILUSTRASI-SOAL.md. Ini adaptasi untuk pembelajaran, bukan klaim seluruh ilustrasi adalah gambar asli buku.

## Nyaman untukmu

Ukuran normal/besar/sangat besar, spasi baca, kontras tinggi, reduce motion, panduan fokus paragraf (sebelumnya/berikutnya), bahasa UI Indonesia/English, panduan keyboard, dan reset preferensi. Preferensi disimpan terpisah dari akun/progres. Materi, diagram, pertanyaan dan pembahasan fisika tetap Indonesia. Bahasa UI menggunakan kamus lokal; tanpa layanan terjemahan atau pengiriman data ke pihak lain.

Pengejar, penalti tangkapan dan Relaxed Mode telah dihapus dari mesin aktif. Data progres versi 4 tetap kompatibel; jawaban, checkpoint dan Adventure Points dipertahankan, kolom mode lama tidak dibaca lagi. Nilai pemahaman tetap berasal dari kuis. Verifikasi perangkat fisik dan audit WCAG penuh belum dilakukan.
